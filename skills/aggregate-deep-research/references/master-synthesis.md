## Portfolio Strategy: The "5-Pack" Blueprint (Detailed)

### Pack 1: Themed Skin Pack (Weeks 1–3)
- **Theme**: Pick underserved niche (e.g., "Retro-Future Workers", "Cryptid Hunters", "Eco-Engineers")
- **Scope**: 12 skins (6 classic + 6 slim) + 3 variants each = 36 files
- **Tools**: Blockbench (skin template), Bridge (manifest), Pixel art workflow
- **Dossier**: Shows — pixel art consistency, manifest correctness, slim/classic handling, packaging

### Pack 2: 64× Texture Pack (Weeks 3–8, parallel)
- **Theme**: Cohesive visual language (e.g., "Paper Craft", "Neon Noir", "Biomechanical")
- **Scope**: All vanilla blocks/items + 3 custom block models (geometry + material)
- **Tools**: Blockbench (models), Paint.NET/Aseprite (textures), Bridge (render controllers)
- **Dossier**: Shows — texture artistry, geometry system, render controllers, material variants, performance

### Pack 3: Scripted Micro-Add-On (Weeks 9–16)
- **Concept**: Single polished mechanic (e.g., "Grappling Hook", "Portable Workbench", "Pet Companion")
- **Scope**: 1 custom entity + 1 custom block + 1 scripted system + UI
- **Tools**: VS Code + Bridge (TypeScript), Blockbench (entity/block), Molang
- **Dossier**: Shows — Script API fluency, component architecture, event handling, tick budget, testing

### Pack 4: Adventure Map (Weeks 17–26)
- **Concept**: 30–45 min focused experience (puzzle, parkour, narrative, survival challenge)
- **Scope**: Custom world + behavior pack (commands/functions) + NPCs + progression + loot
- **Tools**: Bedrock Editor (world), Bridge (functions), NPC dialogue, structure blocks
- **Dossier**: Shows — level design, pacing, command/functions mastery, player onboarding, replayability

### Pack 5: Capstone Mini Mash-up (Weeks 27–40)
- **Concept**: Themed bundle — world + texture pack (32×) + 2 skins + 1 scripted system
- **Scope**: Integration test of all skills; "flagship" quality
- **Tools**: All above + project management (Notion/GitHub Projects)
- **Dossier**: Shows — end-to-end delivery, cross-system integration, performance budgeting, commercial polish

## Go/No-Go Decision Framework

### Proceed If:
- ✅ You enjoy pixel art / low-poly modeling / technical art
- ✅ You can commit 10–15 hrs/week for 12 months
- ✅ You want *shipped products* on your resume, not just tutorials
- ✅ You're comfortable with "hurry up and wait" certification cycles
- ✅ You see this as **Phase 1 of 3-year game dev plan**, not the destination

### Reconsider If:
- ❌ You need income in <6 months
- ❌ You hate Microsoft ecosystems / closed platforms
- ❌ You only want to code (no art/design)
- ❌ You expect Steam-like discoverability
- ❌ You're not willing to market yourself (YouTube/TikTok required)
