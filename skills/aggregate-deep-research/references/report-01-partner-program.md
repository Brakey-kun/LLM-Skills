## Executive Summary

The Minecraft Marketplace Partner Program is a **curated, invite-only/gated program** where Microsoft/Mojang selects creators to sell content (skins, texture packs, worlds, add-ons) via the in-game Marketplace using Minecoins. As of 2026, the program operates on a **70/30 revenue split (creator/Microsoft)**, requires a **portfolio review**, and has **periodically closed/open application windows**. The program is distinct from the Java Edition modding ecosystem — it is Bedrock Edition only, centrally controlled, and all IP sold must be original or licensed.

## 2. Revenue Model & Financial Terms

### Revenue Split
- **70% Creator / 30% Microsoft** — confirmed by multiple sources [Sources 1, 5, 14]
- This is a **take-rate on Minecoin purchases** [Source 5: "take-rate for each transaction in their official marketplace"]
- **Minecoins** are the only currency; purchased with real money, **non-refundable, non-transferable, non-resellable** [Sources 5, 25]

### Payout Mechanics
- **Minecoin → USD conversion**: Not publicly documented at fixed rate; Minecoin bundles sell at ~$0.01/coin (e.g., 320 coins = $3.29, 1020 coins = $9.99)
- **Payout threshold**: Not publicly documented; likely monthly/quarterly via Microsoft Partner Center
- **Tax/regional**: Handled through Microsoft Partner Center (standard Microsoft vendor process)
- **Realms Plus inclusion**: Some partner content included in Realms Plus subscription; revenue share terms not public

## 3. Content Types Accepted

Each content type has distinct technical requirements, file size limits, and review criteria:

| Content Type | Description | Technical Scope | Typical Price Range (Minecoins) |
|--------------|-------------|-----------------|--------------------------------|
| **Skin Packs** | Player/mob skin collections | Texture only (64×64 or 64×32) | 160–320 |
| **Texture Packs** | Block/item/entity retextures | Resource pack (textures + models) | 320–660 |
| **World Templates** | Pre-built maps (adventure, survival, creative) | Structure files + commands + resources | 490–1340 |
| **Add-On Packs** | Behavior + Resource packs (custom entities, blocks, items, mechanics) | JSON definitions + scripts (JS/TS) + assets | 660–1720 |
| **Mash-up Packs** | Themed bundles: world + texture + skins + music + UI | Full package | 990–2500+ |
| **Skin Packs (Animated)** | Animated character skins | Flipbook textures | 320–660 |

[Sources 1, 9, 12, 13]

### Technical Constraints (Bedrock Edition)
- **File size limits**: Vary by type; worlds capped ~100-200MB compressed
- **Version compatibility**: Must work on current stable Bedrock; Preview/branch compatibility tested
- **No external dependencies**: All assets self-contained; no external servers required for core function
- **Scripting**: JavaScript/TypeScript via Script API (limited sandbox); no native code
- **Performance**: Must run on mobile (iOS/Android), console, Windows 10/11, Chromebook

## 4. Portfolio Requirements (What Reviewers Look For)

### From Generalist Programmer (2026) — Most Current Source [Source 1]
> Video chapters: "Portfolio that passes review" | "Requirements" | "Application walkthrough"

**Key Portfolio Criteria:**
1. **Technical Range** — Demonstrate mastery across multiple systems:
   - Custom entities (behavior + models + animations)
   - Custom blocks (shapes, permutations, lighting)
   - Scripting API (JavaScript/TypeScript) — not just JSON
   - UI/UX (custom screens, HUD, menus)
   - World generation (biomes, structures, features)

2. **Polish & Completeness** — Each piece must be "Marketplace-ready":
   - No placeholder textures
   - Proper manifest.json with correct UUIDs, versioning, dependencies
   - Tested on multiple platforms (mobile, console, Windows)
   - Performance profiled (tick time, memory, render cost)

3. **Original IP** — Zero copyrighted content (Disney, anime, other games)
   - EULA strictly enforced: "against EULA to sell mods/skins/merch that infringes on Minecraft IP outside official Marketplace" [Source 5]

4. **Design Cohesion** — Consistent art direction, clear player-facing value proposition

5. **Documentation** — Each project includes:
   - Design doc (1-page: concept, mechanics, target player)
   - Technical spec (systems used, scripts, custom components)
   - Test plan + results
   - Screenshots/video trailer (Marketplace listing quality)

### Minimum Viable Portfolio (Target: 3–5 Projects in <1 Year)
| Project | Scope | Skills Demonstrated | Est. Build Time |
|---------|-------|---------------------|-----------------|
| **1. Polished Skin Pack** | 10–15 themed skins + variants | Texture art, pack manifest, slim/classic variants | 1–2 weeks |
| **2. Texture Pack (64× or 128×)** | Full block/item/entity reskin + custom models | Resource pack pipeline, geometry, materials | 3–6 weeks |
| **3. Scripted Add-On (Small)** | 1 custom entity + 1 custom block + 1 script-driven mechanic | Script API, Molang, entity components, block components | 4–8 weeks |
| **4. World Template (Adventure/Puzzle)** | 30–60 min playtime, custom progression, commands + structures | Structure blocks, command blocks, loot tables, NPC dialogue | 6–10 weeks |
| **5. Full Mash-up Pack (Capstone)** | Themed world + texture + skins + music + UI + 2+ scripted systems | All above + integration, packaging, performance tuning | 8–14 weeks |

**Total**: ~22–40 weeks (5–9 months) — fits <1 year with parallel work

### Portfolio Presentation Format
- **Hosted portfolio site** (GitHub Pages, personal domain, or Notion) — not just file downloads
- **Per-project page**: Playable demo video (1–2 min), screenshots, feature list, tech stack badges
- **GitHub repos** (public or private with access) for code review — scripts, pack structure
- **Bedrock Editor project files** (.mcaddon source) preferred over exported .mcpack

## 5. Application & Review Process

### Steps (from Generalist Programmer walkthrough) [Source 1]
1. **Prepare Portfolio** (see above)
2. **Submit Application** via official portal (requires Microsoft account + Partner Center enrollment)
3. **Automated Checks** — manifest validity, file size, malware scan, IP scan
4. **Human Review** — Mojang/Microsoft content team evaluates:
   - Technical quality (does it work? performance? bugs?)
   - Art quality (professional polish? original style?)
   - Design quality (fun? replayable? clear value?)
   - IP safety (zero infringement risk)
5. **Feedback/Rejection** — specific reasons given; can reapply after improvements
6. **Acceptance** → Partner Agreement signing → Partner Center onboarding
7. **First Submission** — guided publish of first content piece

### Timeline
- **Review time**: 2–8 weeks (varies by queue)
- **Reapplication cooldown**: Not published; likely 3–6 months
- **Partner onboarding**: 1–2 weeks (legal, tax, banking setup)

### Common Rejection Reasons (Community Reports)
- Placeholder/unfinished assets
- Copyrighted IP (even "inspired by" too close)
- Performance issues on mobile/console
- Manifest errors (UUID collisions, version mismatches)
- Lack of technical depth (only texture packs, no scripting/behavior)
- Poor player experience (confusing, buggy, no tutorial)

## 6. Post-Acceptance: Publisher Workflow

### Content Pipeline
1. **Develop** in Bedrock Editor / VS Code + Bridge / custom tools
2. **Test** locally + on target devices (TestFlight/TestFlight equivalent for consoles)
3. **Package** as .mcaddon / .mcpack with valid manifest
4. **Submit** via Partner Center → Certification queue
5. **Certification** — automated + human QA (functionality, performance, policy)
6. **Pricing** — creator sets Minecoin price within tier bands
7. **Publish** — goes live in Marketplace; featured placement possible
8. **Updates** — submit new version; re-certification required for major changes

### Ongoing Requirements
- **Version support**: Update for breaking Bedrock API changes
- **Quality maintenance**: Fix reported bugs; respond to reviews
- **Policy compliance**: No policy-violating updates; Microsoft can delist
- **Sales reporting**: Monthly via Partner Center

## 8. Alternative/Adjacent Paths

### Minecraft Affiliate Program (NEW, 2026) [Source 11]
- **Lower barrier**: No portfolio review; apply via link
- **Commission**: Earn % on Minecoin purchases driven by your referral links
- **Use case**: Content creators (YouTube, TikTok, streamers) with audience
- **Not a substitute** for Partner Program; complementary

### Modrinth / CurseForge / Planet Minecraft
- **Open platforms** — no application
- **Java Edition focus** (Bedrock support limited)
- **Revenue**: Donations, Patreon, ad rev-share (Modrinth), not direct sales
- **Portfolio value**: Can demonstrate skill; some partners started here

### Realms Plus Content
- Selected partner content bundled in Realms Plus subscription
- Separate negotiation; recurring revenue share
- Not guaranteed for all partners
