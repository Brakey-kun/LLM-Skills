## Executive Summary

The Minecraft Bedrock Marketplace offers a **real but gated revenue path**: 70/30 split, Minecoin economy, 150M+ monthly players. However, **discovery is the bottleneck** — no public search API, algorithmic featuring, saturated categories. Success requires treating it as a **product business**, not just content upload. Portfolio strategy must demonstrate *range + polish + technical depth* in <1 year. Audience building happens **outside** the Marketplace (YouTube, TikTok, Discord, Planet Minecraft) then funnels in.

## 1. Revenue Model Mechanics

### 1.1 The 70/30 Split
- **Creator receives**: 70% of Minecoin price
- **Microsoft retains**: 30% (platform fee + payment processing + Minecoin infrastructure)
- **Comparable to**: Apple App Store (70/30), Steam (70/30 up to $10M), Roblox (~70/30 after fees)
- **Better than**: Modrinth (90%+ to creator but no direct sales; donation/ad-based)

### 1.2 Minecoin Economy
| Bundle | USD Price | Minecoins | $/Coin | Effective Creator $/Coin (70%) |
|--------|-----------|-----------|--------|-------------------------------|
| 320 | $1.99 | 320 | $0.0062 | $0.0043 |
| 1,020 | $5.99 | 1,020 | $0.0059 | $0.0041 |
| 1,720 | $9.99 | 1,720 | $0.0058 | $0.0041 |
| 3,500 | $19.99 | 3,500 | $0.0057 | $0.0040 |
| 7,000 | $39.99 | 7,000 | $0.0057 | $0.0040 |

**Key Insight**: Players buy in bundles; creator earns ~$0.004/Minecoin. A 660-coin pack = **~$2.64 to creator**.

### 1.3 Payout Mechanics
- **Threshold**: Likely ~$50–$100 USD equivalent (standard Partner Center)
- **Schedule**: Monthly (Partner Center standard)
- **Tax**: Microsoft collects W-8BEN/W-9; withholds per treaty
- **Currency**: Paid in USD to bank account
- **Chargebacks**: Microsoft absorbs; creator keeps 70% of net

### 1.4 Real Creator Earnings Estimates (Tiered)

| Tier | Description | Monthly Gross (Est.) | Annual Gross (Est.) | Sources |
|------|-------------|---------------------|---------------------|---------|
| **Low** | 1–2 skin packs, minimal marketing, no featuring | $50–$300 | $600–$3,600 | [2, 4, 13] |
| **Mid** | 3–5 packs (mix types), consistent updates, social presence, occasional feature | $500–$3,000 | $6,000–$36,000 | [1, 2, 4, 5] |
| **High** | 10+ packs, mash-ups, Realms Plus inclusion, strong brand, cross-platform audience | $5,000–$25,000+ | $60,000–$300,000+ | [1, 3, 5, extrapolated] |

**Reality Check**: Most accepted partners earn **Low to Low-Mid** first year. Mid+ requires portfolio depth + marketing + featuring luck. High is studio territory.

### 1.5 Platform Comparison (2019–2026) [Source 5]

| Platform | Creator Rev Share | Primary Model | Audience | Barrier |
|----------|------------------|---------------|----------|---------|
| **Minecraft Marketplace** | ~70% | Direct sale (Minecoin) | 150M+ MAU (Bedrock) | Application + curation |
| **Roblox** | ~70% (after fees) | Microtransactions (Robux) | 70M+ DAU | Open (DevEx req.) |
| **Fortnite UEFN** | ~40% (island revenue) | Engagement payout | 230M+ MAU | Open (application for payout) |
| **Core** | ~50% | Microtransactions | ~5M MAU | Open |
| **Modrinth (Java)** | 90%+ | Donations/ads | ~10M MAU | Open |

**Takeaway**: Marketplace has **highest friction to entry** but **captive paying audience** (kids/parents with Minecoin balances). Roblox/UEFN have larger creator bases but more competition.

## 2. Discovery & Audience Building

### 2.1 The Discovery Problem
- **No public search API** — can't SEO optimize externally
- **Marketplace search** — basic keyword/tags; weighted by sales, rating, recency
- **Featuring** — only path to massive visibility; controlled by Mojang curation team
- **Categories** — Skins, Worlds, Texture Packs, Mash-ups, Adventures; each has top charts

### 2.2 Traffic Sources (Ranked by Impact)
| Source | Control | Conversion | Effort |
|--------|---------|------------|--------|
| **Marketplace Feature (Hero/Category)** | None (curated) | Very High | Portfolio quality + luck |
| **Marketplace Search/Charts** | Partial (metadata) | Medium | Ongoing optimization |
| **YouTube/TikTok/Shorts (Own)** | Full | High (if audience matches) | High (content creation) |
| **Creator Collaborations** | Partial | Medium-High | Medium |
| **Planet Minecraft / MCPEDL / CurseForge** | Full | Low-Medium | Low-Medium |
| **Discord/Reddit Communities** | Partial | Low | Medium |
| **Affiliate Links (New Program)** | Full | Trackable | Low |
| **Realms Plus Inclusion** | Negotiated | Recurring | High (relationship) |

### 2.3 Audience Building Strategy (12-Month Plan)

#### Months 1–3: Foundation
- **Portfolio site** (GitHub Pages / Notion / personal domain)
- **YouTube channel**: Devlogs (1/week), tutorials (1/month), showcase (per release)
- **TikTok/Reels/Shorts**: 30-sec process clips, "how I made X", before/after
- **Twitter/X**: Daily progress, #MinecraftMarketplace, #BedrockAddon tags
- **Planet Minecraft**: Upload free versions / teasers (link to Marketplace)

#### Months 4–6: First Release + Momentum
- **Launch week**: Coordinated posts across all platforms
- **Affiliate links** in all descriptions (new program)
- **Engage** every comment; build Discord community (even 50 members)
- **Pitch** to mid-tier YouTubers (10K–100K subs) for showcase

#### Months 7–12: Scale
- **Cross-promote** between packs (bundle discounts)
- **Seasonal content** (Halloween, Winter, Summer updates)
- **Community requests** → build → credit contributors
- **Apply for featuring** (Partner Center has "request feature" form)
- **Collaborate** with other partners (cross-packs, bundles)

### 2.4 Content Marketing That Works for Minecraft
| Format | Example | Why It Works |
|--------|---------|--------------|
| **Devlog series** | "Building a Magic System in Bedrock: Ep 1–10" | Shows technical depth; builds anticipation |
| **Speed-build + timelapse** | "I made a working car in 1 hour" | Shareable; shows skill |
| **Tutorial** | "How to make custom blocks in 1.21" | SEO traffic; establishes authority |
| **Player reaction** | "Kids play my map for first time" | Social proof; emotional |
| **Behind-the-scenes** | "Why my pack was rejected (and how I fixed it)" | Authentic; helps others trust; transparency |

## 3. Portfolio Strategy: <1 Year to Partner-Ready

### 3.1 What Reviewers Actually Look For (Inferred from [1, 2, 15])

| Criterion | Weight | Evidence |
|-----------|--------|----------|
| **Technical Range** | High | Skin + Texture + Scripted + World |
| **Polish / UX** | Critical | No bugs, clear tutorial, good performance |
| **Originality** | High | Not "another furniture pack"; unique mechanic/theme |
| **Commercial Viability** | Medium | Clear audience, price-appropriate scope |
| **Presentation** | Medium | Professional screenshots, trailer, description |
| **Completeness** | Critical | Shipped, tested, documented |

### 3.2 The "5-Pack Portfolio" Blueprint (26–38 Weeks)

| Pack # | Type | Scope | Skills Proven | Weeks | Parallel? |
|--------|------|-------|---------------|-------|-----------|
| **1** | **Skin Pack** (Themed) | 12 skins (6 classic + 6 slim) + variants | Pixel art, manifest, slim/classic, packaging | 2–3 | Yes (art) |
| **2** | **Texture Pack** (64×) | Full block/item reskin + 3 custom models | Texture art, geometry, materials, render controllers | 4–6 | Yes (art) |
| **3** | **Scripted Add-On** (Micro) | 1 custom entity + 1 custom block + 1 mechanic (e.g., grappling hook) | Script API, Molang, components, events, testing | 5–8 | After #1 |
| **4** | **Adventure Map** (30–45 min) | Custom progression, NPCs, loot, 3–5 areas | Commands, structures, NPC dialogue, pacing, playtesting | 6–8 | After #2 |
| **5** | **Capstone: Mini Mash-up** | Themed world + texture + 2 skins + 1 scripted system | Integration, project management, performance, polish | 8–12 | Last |

**Total Calendar Time**: ~26–38 weeks (6–9 months) with parallel art tracks
**Buffer**: 2–4 weeks for polish, portfolio site, application prep

### 3.3 Portfolio Presentation Package

Each project needs a **Project Dossier** (1-page PDF + web page):

```
[Project Name] — [Type] — [Engine Version]
├── Tagline (1 sentence)
├── Trailer (60–90 sec, YouTube unlisted)
├── Screenshots (5–8, 1920×1080, curated)
├── Feature List (bulleted, player-facing)
├── Tech Stack (badges: Resource Pack, Behavior Pack, Script API, Molang, Blockbench, Bridge)
├── Dev Time (calendar weeks)
├── Test Report (devices tested, tick perf, known issues)
├── Design Doc Link (Notion/GitHub — 2–3 pages)
├── Source Access (GitHub repo — private, invite reviewers)
└── Marketplace-Ready Checklist ✓
```

### 3.4 Portfolio Site Structure (Single Page)
```
Hero: "Minecraft Bedrock Creator Portfolio — [Name]"
├── About (3 lines: focus, experience, goal)
├── Projects Grid (5 cards → click → Dossier modal)
├── Skills (visual: Resource Pack ●●●●○, Script API ●●○○○, etc.)
├── Process (3-step: Design → Build → Polish)
├── Contact (Email, Discord, Partner Center ID if applicable)
└── Blog/Devlog (3 latest posts)
```

**Tech**: GitHub Pages (free, custom domain), Astro/Next.js/Hugo, or Notion + Super.so
